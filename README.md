# Nexus Research Journal

Website for [Nexus Research Journal](https://nexusresearchjournal.com), a free student research journal I co-founded that has reached 1,700+ students across 3 countries. It connects student researchers with PhD mentors and publishes peer-reviewed student papers.

**Live site:** https://nexusresearchjournal.com

## Pages

- **Home:** mission and student testimonials
- **About:** the journal and its panels of expert judges
- **Publications:** published student papers
- **Guidelines:** submission rules
- **Get Involved:** the paper application form, the student peer review board, and workshop videos
- **News:** journal updates

## Tech stack

- HTML, CSS (Sass), and JavaScript
- Bootstrap and jQuery
- Google Forms for submissions and sign-ups
- Hosted on GitHub Pages with a custom domain

## Run it locally

No build step is needed. Clone the repo and open `index.html` in a browser.
